# COA OEE — Versão PWA

Esta versão pode ser instalada como aplicativo no celular ou computador.

## Arquivos
- index.html
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

## Importante
PWA precisa ser publicado em HTTPS (GitHub Pages funciona) ou executado em localhost.
Abrir apenas com file:// não permite instalar o app nem registrar o Service Worker.

## Instalação
Android/Chrome/Edge:
1. Abra o site publicado.
2. Clique em "Instalar aplicativo" quando o botão aparecer.
3. Se o botão não aparecer, use o menu do navegador > Instalar app / Adicionar à tela inicial.

iPhone/iPad:
1. Abra no Safari.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início".

## Atualização
Quando alterar o sistema, publique novamente os arquivos no mesmo repositório.
